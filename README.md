One line roasting a smart fridge, entered in the [make.fun](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) bounty "Fridge Roast: One Line, Biggest Laugh". A judge model reads the lines two at a time and picks the one that lands hardest — the funniest lines split the $5 pool.

> "My fridge updated its firmware overnight, and now the ice maker holds my ice hostage until I accept its terms and conditions."

## Run it

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. Python 3 standard library only, deterministic — running it twice produces byte-identical output.
